### `--kml-track` (Google Earth Animated Tracks)

- Generates `_track.kml` with `gx:Track` elements, one per mower
- Synthetic `<when>` timestamps spaced by haversine distance / 1.0 m/s
- All mowers share the same base start time — animate in parallel via Google Earth timeline
- Distinct line/icon color per mower (20-color palette)
- `gx:coord` uses correct KML `lon lat alt` space-separated format

### `--kml-tour` (Cinematic Flyover)

- Generates `_tour.kml` with `gx:Tour` containing a `gx:Playlist` of `gx:FlyTo` directives
- Camera follows mower 1's path with heading tracking via bearing computation
- `LookAt` camera: altitude 30m, tilt 60°, range 50m, smooth fly mode
- All mower paths rendered as static `LineString` placemarks (visible during tour)
- FlyTo duration clamped to [0.5, 5.0] seconds per segment

### Usage

```bash
nav-plan input/700.kml --width 21 --kml-track          # Animated tracks
nav-plan input/700.kml --width 21 --kml-tour            # Cinematic flyover
nav-plan input/700.kml --width 21 --visualize --kml-track --kml-tour  # All three
```

Output files use `_track.kml` and `_tour.kml` suffixes to avoid overwriting the input `.kml` boundary file.
