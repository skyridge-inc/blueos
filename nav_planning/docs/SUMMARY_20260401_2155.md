### Visualization Features

- Leaflet.js map with Esri World Imagery satellite tiles (no API key required)
- Each mower path rendered as a distinct colored polyline (20-color palette, cycles)
- Animated circle markers move along each path from start to finish
- Play/Pause button and Reset button
- Speed slider (1x–10x)
- Per-mower visibility toggles with color indicators
- Map auto-centers and zooms to fit all paths
- Self-contained HTML (CDN references only, opens in any browser)

### Usage

```bash
nav-plan input/700.kml --width 21 --visualize
# Produces: input/700_mower1.waypoints ... input/700_mower41.waypoints
#           input/700.html (open in browser)

nav-plan input/700.kml --width 21 --visualize -o output/mission
# Produces: output/mission_mowerN.waypoints + output/mission.html
```
